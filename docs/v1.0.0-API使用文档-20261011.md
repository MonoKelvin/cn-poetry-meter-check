> 本文仅提供中文说明。基础检测为纯算法、可离线；高级检测与推荐可选接入大模型。

## 1. 安装与构建

```bash
npm install          # 安装依赖
npm run build        # 产出 dist（ESM + CJS + d.ts）
npm test             # 运行测试
```

发布后使用：`npm i cn-poetry-meter-check`。

## 2. 基础检测

```ts
import { checkMeter } from 'cn-poetry-meter-check'

const r = checkMeter('白日依山尽，黄河入海流。欲穷千里目，更上一层楼。')
r.form?.name          // '五言绝句'
r.form?.variant       // { start: 'oblique', firstLineRhymes: false }
r.inferredRhymeGroup  // '十一尤'
r.passed              // true
r.issues              // 问题列表（见 §4）
```

可复用检测器（固定选项）：

```ts
import { PoetryChecker } from 'cn-poetry-meter-check'
const checker = new PoetryChecker({ rhymeBook: 'pingshui', strictness: 'normal' })
checker.check('……')
```

`CheckOptions`：`form?`（'auto' | 'wujue' | 'wulv' | 'qijue' | 'qilv'）、`rhymeBook?`（见 §3）、`strictness?`（'strict' | 'normal' | 'loose'）。

## 3. 韵表

默认平水韵；可切换中华新韵、词林正韵。中华通韵依今音，用 pinyin-pro 映射 16 韵：`registerRhymeTable(await createTongyunRhymeTable())` 注册后即可用 `rhymeBook: 'tongyun'`。

```ts
import { getRhymeTable, registerRhymeTable } from 'cn-poetry-meter-check'
checkMeter(poem, { rhymeBook: 'xinyun' })      // 'pingshui' | 'cilin' | 'xinyun' | 'tongyun'
getRhymeTable('pingshui').getToneInfo('长')     // { tones:['level','oblique'], groups:[...], isPolyphone:true }
registerRhymeTable(myTongyunTable)              // 自定义/补充韵表（实现 RhymeTable 接口）
```

## 4. 检测结果结构

```ts
interface CheckResult {
  form?: { id, name, variant }       // 诗体与变体（平起/仄起、首句入韵）
  rhymeBook: RhymeBookId
  inferredRhymeGroup?: string        // 推断主韵部
  passed: boolean                    // 无 error 即通过
  issues: Issue[]
  stats: { errors, warnings, infos }
}
interface Issue {
  level: 'error' | 'warning' | 'info'
  category: 'form'|'ti'|'dui'|'nian'|'rhyme'|'guping'|'sanping'|'sanze'|'aojiu'|'polyphone'|'pingze'|'duizhang'
  position?: { lineIndex, couplet, role:'chu'|'dui', charIndex, char }
  message: string                    // 中文说明
}
```

类别：`ti` 失替、`dui` 失对、`nian` 失粘、`guping` 孤平、`sanping` 三平调、`sanze` 三仄尾、`aojiu` 拗救/变格（提示）、`polyphone` 多音字（提示）。

## 5. 高级检测（对仗 / 多音字消歧）

```ts
import { createAdvancedChecker, loadSkillText } from 'cn-poetry-meter-check'

// 启发式（无需大模型）：校验等长 + 节奏点平仄相对
const adv = createAdvancedChecker()
await adv.duizhang.check('两个黄鹂鸣翠柳', '一行白鹭上青天')
// { isParallel, confidence, issues, notes }

// 接入大模型后，判工对/宽对/合掌，并可做多音字消歧
const skill = await loadSkillText('detect-duizhang')
const adv2 = createAdvancedChecker({ ai: cfg, duizhangSkill: skill })
```

多音字消歧并复检（将确定读音回灌基础检测，消解歧义提示、暴露确定读音下的真实出律）：

```ts
import { checkMeterResolved } from 'cn-poetry-meter-check'
const { result, resolutions } = await checkMeterResolved(poem, advanced.polyphone!)
// result：消歧后复检结果；resolutions：各多音字的定音记录
```

## 6. 推荐（LLM，FR-C1..C6）

```ts
import { createRecommender, loadSkillText } from 'cn-poetry-meter-check'

const rec = createRecommender({
  ai: cfg,
  skills: { 'compose-poem': await loadSkillText('compose-poem') },
})
await rec.composePoem({ form: 'wujue', theme: '秋山行旅', rhyme: '平水韵 下平十一尤' })
// { recommendations: [{ text, reason }] }
```

六项方法：`fixMeter`（出律补救）、`fixDuizhang`（对仗替换）、`composePoem`（成诗）、`completeLine`（补句）、`fillChar`（填字）、`recommendEye`（字眼）。未配置 `ai` 或缺对应 SKILL 时返回 `{ recommendations: [], notImplemented: true }`。

## 7. 大模型配置

将各家 API 写入本地 `cpmc.apis.json`（**含密钥，已在 .gitignore 中，禁止提交**；模板见 `cpmc.apis.example.json`），支持多套：

```json
{
  "default": "my-llm",
  "apis": [
    { "name": "my-llm", "provider": "anthropic", "baseUrl": "https://api.anthropic.com", "apiKey": "sk-...", "model": "claude-..." }
  ]
}
```

```ts
import { loadLlmConfigs, pickLlmConfig } from 'cn-poetry-meter-check'
const file = await loadLlmConfigs()          // 默认读取 cpmc.apis.json
const cfg = pickLlmConfig(file, 'my-llm')    // 省略名称则用 default/首项
```

- `provider: 'openai-compat'`：OpenAI、通义千问(兼容模式)、DeepSeek、Kimi——仅 `baseUrl + model + apiKey` 不同。
- `provider: 'anthropic'`：Claude 接口规范（`/v1/messages`、`x-api-key`、`anthropic-version`）。
- 也可直接 `import { createLlmClient } from 'cn-poetry-meter-check'` 自行构造客户端。

## 8. SKILL

SKILL.md 位于 `skills/<技能名>/SKILL.md`，Node 下用 `loadSkillText(name)` 读取；浏览器环境请直接将文本传入检测器/推荐器。结构化输出统一经 `json_object` + 提示内嵌 schema + Zod 校验与重试。

## 9. 注意事项

- 平仄一律查韵书字表判定，不用拼音（入派三声）；今音韵表（新韵/通韵）才依今声调。
- 多音字在要位给“歧义提示”（info），确切取音需上下文/大模型消歧。
- 拗救与特拗（平平仄平仄）视为合律，给“已拗救/变格”提示而非错误。
- 大模型调用需有效 API Key；基础检测则完全离线、无网络依赖。
