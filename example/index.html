近体诗 · 格律检测

格律，逐字可见

输入一首近体诗，即时标出每字平仄，并校验押韵、粘对、孤平与拗救。纯算法、可离线。

检测

平 仄 两可 韵脚 出律 多音

能做什么

基础检测，离线可跑
诗体识别、平仄、押韵（落韵/重韵）、替粘对、孤平、三平调、拗救与特拗、多音字歧义，皆纯算法，零网络。
多部韵表
平水韵（中古音含入声，广韵平仄兜底）、词林正韵、中华新韵；中华通韵依今音映射。可切换、可扩展。
对仗与推荐
对仗启发式免联网；接入大模型可判工对与合掌，并补救出律、替换对仗、成诗、炼字。
工程
TypeScript，产出 ESM、CJS 与类型声明；Zod 校验、单元测试、持续集成；MIT 许可。

对仗检测

免联网的启发式校验：等长与节奏点平仄相对。

上手

安装 · 最基础

# 安装
npm i cn-poetry-meter-check

import { checkMeter } from 'cn-poetry-meter-check'

const r = checkMeter('白日依山尽，黄河入海流。欲穷千里目，更上一层楼。')
r.form.name           // '五言绝句'
r.inferredRhymeGroup  // '十一尤'
r.passed              // true

检测选项与结果

const r = checkMeter(poem, {
  form: 'auto',          // 'auto' | 'wujue' | 'wulv' | 'qijue' | 'qilv'
  rhymeBook: 'pingshui', // 'pingshui' | 'cilin' | 'xinyun' | 'tongyun'
  strictness: 'normal',  // 'strict' | 'normal' | 'loose'
})

r.passed    // 无 error 即 true
r.stats     // { errors, warnings, infos }
r.issues    // [{ level, category, message, position?, suggestion? }]
r.lines     // 逐句逐字：[{ cells: [{ char, tone, expected?, isRhyme? }] }]

复用检测器 · 多韵表

import { PoetryChecker, getRhymeTable, createTongyunRhymeTable, registerRhymeTable } from 'cn-poetry-meter-check'

// 固定一组选项，多次检测
const checker = new PoetryChecker({ rhymeBook: 'cilin', strictness: 'strict' })
checker.check(poemA); checker.check(poemB)

// 直接查字的平仄 / 韵部
const t = getRhymeTable('pingshui')
t.getToneInfo('山')       // { tones, groups, isPolyphone }
t.isSameRhyme('流', '楼')  // true

// 中华通韵（今音，需可选依赖 pinyin-pro）
registerRhymeTable(await createTongyunRhymeTable())
checkMeter(poem, { rhymeBook: 'tongyun' })

对仗 · 多音字（高级，免联网）

import { createAdvancedChecker } from 'cn-poetry-meter-check'

// 不配 ai：对仗走启发式（等长 + 节奏点平仄相对）
const adv = createAdvancedChecker()
const d = await adv.duizhang.check('两个黄鹂鸣翠柳', '一行白鹭上青天')
d.isParallel  // true | false | null
d.confidence  // 0 ~ 1

SKILL 传入 · 字符串 / 内置文件 / 自定义路径

import { loadSkillText, createAdvancedChecker } from 'cn-poetry-meter-check'
import { readFile } from 'node:fs/promises'

// 1) 直接字符串（支持 {{var}} 占位）
const inline = '你是对仗检测专家，判定 {{chu}} 与 {{dui}} 是否工对。'
// 2) 内置技能文件 skills/<name>/SKILL.md（仅 Node）
const polyphoneSkill = await loadSkillText('resolve-polyphone')
// 3) 自定义路径：自行读取文本后传入
const duizhangSkill = await readFile('./skills/duizhang.md', 'utf8')

const adv = createAdvancedChecker({ ai, duizhangSkill, polyphoneSkill })
await adv.duizhang.check(chu, dui)   // 有 ai+skill 时走大模型，判工对/合掌
await adv.polyphone.resolve('重', '轻舟已过万重山', 6)

推荐 · 补救 / 对仗 / 成诗 / 补句 / 填字 / 字眼

import { createRecommender, loadSkillText } from 'cn-poetry-meter-check'

const rec = createRecommender({
  ai,
  skills: { 'compose-poem': await loadSkillText('compose-poem') },
})
await rec.fixMeter(poem)                                 // 出律补救
await rec.fixDuizhang('两个黄鹂鸣翠柳', '一行白鹭上青天')  // 对仗替换
await rec.composePoem({ form: 'qijue', theme: '秋江晚望', rhyme: '平水韵 十一尤' })
await rec.completeLine('两个黄鹂鸣翠柳', 'chu')           // 补对句
await rec.fillChar('白日依□尽，黄河入海流。……')          // 填字
await rec.recommendEye(poem)                             // 字眼（五言第三/七言第五字）
// 未配 ai 时返回桩实现：{ recommendations: [], notImplemented: true }
